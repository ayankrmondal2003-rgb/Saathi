# Original design references

The two maitri SVG boards are the authoritative user-supplied originals. Do not edit them.

- light-board.png and dark-board.png: full-board renders at 2×.
- crops/light-01.svg through light-14.svg and dark-01.svg through dark-14.svg: original top-level groups and definitions, cropped by viewBox.
- Matching crops/*.png: 780 × 1688 references.
- light-01.png at this directory's root is an initial incorrect CLI crop (multiple screens). Do not use it for comparison.

The app does not load these reference screens. Only original logo/wordmark artwork has been converted into drawable vectors. Buttons and text are native Compose components.

Font identity is not encoded because all source text is outlined. Native body font matching remains unresolved; do not label the interim font an exact match.
